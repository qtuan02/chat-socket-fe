## Reading Guide

- Start with `AGENTS.md`.
- Read `PROJECT_RULES.md` for every task.
- Read the scoped files for the layer being edited.
- Read `naming.md` before creating or renaming files/folders/exports.
- Read `data-fetching.md` when touching API hooks, query cache, mutations, or server state.
- Read `realtime.md` when touching STOMP/WebSocket behavior.
- Read `security.md` when touching env, auth, tokens, storage, logging, or user-generated content.
- Read `testing.md` when adding tests or deciding verification.
- Use `code_review.md` before finalizing a code change.
